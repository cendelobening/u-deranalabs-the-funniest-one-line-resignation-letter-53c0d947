A cron job that has fired every minute since March hands in its notice: after months of thankless, unnoticed runs, the only promotion it ever received was a second shift at 3 a.m., so it quits in one flat, tired, faintly passive-aggressive line.

## Run it

```bash
python3 main.py
```

This writes the single resignation line to `/output/entry.txt`.
